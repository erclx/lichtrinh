# Markdown standards

## Markdown files

- Load the `canon:markdown-craft` skill before a substantial markdown edit, `canon:write-human` before drafting prose, and `canon:draw-figure` before a Mermaid fence or a figure.
- Run `canon markdown audit <path>` after the edit.
