# Language standards

## Repository text

- Write code, comments, commits, and docs in English. Vietnamese belongs only in translation files and in test fixtures that exercise it.
- Keep the Vietnamese copy in a design frame, on the board and under `canon/design/`, since every frame carries a VI and EN toggle.
- Keep the owner panel's frames under `canon/design/panel/` in English, with invented Vietnamese in their Messages rows alone.
