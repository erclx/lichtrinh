# Design frame standards

## Language

- Give every frame a VI and EN toggle with a 64px tap area, defaulting to English, so the operator reads each frame in both languages.

## Icons

- Draw every control icon as an inline SVG, such as a chevron or a mic, never as a typed glyph like `‹` or an emoji, which renders differently on each device.
