# Security policy

Accounts, sessions, and the tunnel that lets the app reach the assistant on the owner's computer are the security-sensitive parts, since anyone signed in can send the assistant a message.

## Reporting a vulnerability

Report it privately through GitHub's [private vulnerability reporting](https://github.com/erclx/lichtrinh/security/advisories/new). Do not open a public issue for it.

Include the version, your OS, and the steps that reproduce the problem. You get a reply in the advisory thread.

## Supported versions

Only the latest release receives fixes.
